# OpenCode run budget E2E check

Временный файл для проверки лимита `/oc` на один PR. Ветку и PR нужно закрыть после
проверки, в `main` этот файл не вливается.

Ожидаемое поведение бюджета:

1. первый `/oc` — разрешён, агент вызывается;
2. второй `/oc` — разрешён, агент вызывается;
3. третий `/oc` — разрешён, агент вызывается;
4. четвёртый `/oc` — `limit_exhausted`, модель не вызывается, публикуется отчёт
   с последним SHA, ссылкой на логи и статусом «нужен человек».

Команды лучше отправлять по одной и дожидаться завершения запуска, потому что
`concurrency` не отменяет текущий запуск, но лишние ожидающие запуски могут быть
отменены GitHub и всё равно расходуют попытку.
